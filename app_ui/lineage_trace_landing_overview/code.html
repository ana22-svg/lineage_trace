Forensic Methodology

How It Works: Ingestion to Attribution

01

Distributed Ingestion

Multi-platform scrapers listen on Telegram public channels, X streams, Reddit hubs, and RSS news feeds in real time.

02

Embedding & Deduplication

Cross-language transformer models extract core semantic claims, stripping layout noise, hashtags, and tracking redirects.

03

Lineage Graph Construction

[Active Step]

Timestamp-ordered DAG (Directed Acyclic Graph) is built connecting ancestor nodes to descendants via semantic mutation vectors.

04

Mutation Diff Analysis

Entity-level diffing flags added adjectives, removed conditionality, source fabrication, and sentiment escalation per edge.

05

Topology & Velocity Computation

Cluster propagation curves are matched against known astroturf topologies and rapid-fire algorithmic bot networks.

06

Alerting & Exportable Dossiers

Structured JSON and timeline evidence exports sent directly to newsroom CMS workflows, Slack desks, or OSINT repositories.
